# Architecture Decision Records

One file per decision with lasting consequences: `NNN-short-title.md`.

Format, kept deliberately short:

```
# NNN — Title

**Date:** YYYY-MM-DD
**Status:** accepted | superseded by NNN

## Context
What forced a decision. The constraints in play.

## Decision
What was chosen, stated plainly.

## Consequences
What this makes easy, what it makes hard, what it forecloses.

## Alternatives rejected
What else was considered and the honest reason it lost.
```

An ADR that only argues for the choice made is not useful. Record the case against it too —
that is what makes it worth reading in a year.
